# Portfólio Acadêmico - Análise e Desenvolvimento de Sistemas

Portfólio web profissional e responsivo desenvolvido como projeto acadêmico para demonstrar competências em desenvolvimento Front-End, aplicando boas práticas de estruturação de código, design responsivo e integração de componentes de frameworks modernos.

---

## Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

* **HTML5**: Estruturação semântica do conteúdo.
* **CSS3**: Estilização customizada, Flexbox e regras de responsividade (*Media Queries*).
* **JavaScript (ES6+)**: Dinamismo e interatividade da página.
* **Bootstrap 5**: Utilizado para implementação de componentes nativos avançados (Carrossel de Certificados).
* **Git & GitHub**: Controle de versão e hospedagem do código-fonte.

---

## Funcionalidades e Seções

* **Seção Hero / Sobre Mim**: Apresentação pessoal com foto de perfil estilizada, links diretos para redes sociais (LinkedIn e GitHub) e layout em colunas flexíveis.
* **Carrossel de Certificados (Bootstrap)**: Componente interativo em carrossel para exibição de certificações acadêmicas e profissionais.
* **Design Responsivo**: Layout totalmente adaptado para diferentes tamanhos de tela (Desktops, Tablets e Smartphones).
